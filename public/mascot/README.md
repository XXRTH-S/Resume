# Bubble - fluffy redesign

`bubble-fluffy-atlas.png` is the current 1254 x 1254 transparent PNG atlas, made with the built-in Imagegen tool without supplying the previous cartoon references. Bubble now has plush charcoal-gray fur, rounded cheeks, a white chest tuft, proportionate eyes, and a pink nose. This is an original design direction, not a claim of legal clearance or guaranteed uniqueness.

## Animation

Four equal cells, in reading order: seated idle, relaxed blink, laptop typing with the first paw raised, laptop typing with the alternate paw raised. The bottom pair alternates during an API request and briefly when the answer arrives. Pause and reduced-motion settings keep a still frame. Desktop size is 124px; mobile remains 80px, with a soft white CSS shadow. This is a 2D sprite mascot, not a rigged 3D model.

## Generation prompt

Create an ORIGINAL fluffy kitten mascot named Bubble for a developer portfolio, not based on any existing fictional character or franchise. No reference images. A cuddly charcoal-gray longhair kitten with rounded pear-shaped body, small rounded triangular ears with WHITE inner fur, soft feathery cheek tufts, a little white chest tuft, short plush paws, a fluffy curled tail, a tiny pastel PINK nose, modestly sized expressive eyes with WHITE sclera and dark slate irises, friendly sweet face. Eyes should NOT dominate the head. Soft dimensional storybook gouache/plush illustration, visible silky fur clumps, cool gray highlights, no hard thick cartoon outlines. Create ONE square 2x2 sprite atlas with four exactly equal cells; all characters centered on the same baseline with generous 12% clear padding, full body visible. Top left: seated idle, gentle smile, paws together. Top right: same silhouette and pose, eyes closed in a relaxed blink. Bottom left: same kitten behind a small plain muted-lilac laptop with NO LOGO, left paw raised over keyboard and right paw pressing a key, face visible above screen. Bottom right: EXACT same kitten and laptop location as bottom left, swap the paw positions, right paw raised and left pressing a key, slight delighted smile. These two bottom frames form a typing animation. No extra objects, no text, no border, no ground shadow. Genuine transparent alpha PNG background, NOT a checkerboard illustration. The style must be visually distinct from flat black cats with oversized cream eyes and geometric faces.
